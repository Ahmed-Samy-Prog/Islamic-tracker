# Islamic Tracker - متابعة العبادات

A beautiful Islamic tracker app for every day of the year to track daily prayers, good deeds, Quran reading, and more.

## Features
- 🌙 Track 5 daily prayers
- 💚 Track good deeds (charity, family ties, etc.)
- 📖 Track Quran reading
- ☀️ Morning/evening Adhkar
- 🌙 Nawafil prayers tracking
- 📅 Calendar view with daily progress
- 🌟 Mood tracking based on completion

## Technologies Used
- React 19
- Tailwind CSS
- Lucide React Icons
- Vite
